# DRISHTI UI Refresh

This branch contains presentation-only improvements for the DRISHTI frontend.

## Design direction

- Institutional government-tech visual language
- DRISHTI navy, teal, green, amber, restrained red
- Noto Sans / system font stack
- Clear hierarchy, evidence-first layouts, restrained motion
- Consistent cards, controls, status chips, focus states, and responsive spacing

## Functional protection

No backend files, API service files, inspection calculations, OCR logic, compliance rules, report generation, offline capture storage, authentication endpoints, or routing logic are intentionally changed by this refresh.

The UI refresh checkpoint before the full-page pass is:

`checkpoint/ui-refresh-safe-2026-09-11`

The final visual-review checkpoint is created separately after deployment verification.
