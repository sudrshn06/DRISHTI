# DRISHTI Real-World Validation Benchmark

This directory contains the lightweight benchmark framework for evaluating DRISHTI against real package images.

## Structure
- `manifest.csv`: The CSV file listing all evaluation package images, metadata, and expected categories.
- `run_benchmark.py`: Python script running OCR, extraction, and compliance rule verification on images listed in the manifest.
- `images/`: Local repository directory for actual evaluation images.
- `results/`: Contains execution metrics generated by the runner (`latest.json` and `latest.csv`).

## Usage
Run the benchmark runner inside the backend container:
```bash
docker-compose exec -T backend python benchmark/run_benchmark.py
```
